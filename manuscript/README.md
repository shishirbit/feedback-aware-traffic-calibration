# Results in Engineering manuscript

`main.tex` is the authoritative single-file manuscript source, using the supplied Elsevier CAS `cas-sc` class. It contains every section, both algorithms, all 19 tables, eight figure environments, the declarations, and the 26-entry numbered bibliography, ordered by first citation. Both authors use one shared departmental affiliation. Vector PDF figures are in `figures/`; the architecture is not TikZ.

`results-in-engineering-overleaf.zip` is the self-contained Overleaf source package; `main.pdf` is the compiled preview. Open the ZIP in Overleaf and select XeLaTeX. A separate editable `highlights.txt` is included in the package. No BibTeX step is required. CAS `pos=` placement keys and float barriers keep figures/tables near their source and before the bibliography.

The numerical results and registered claim boundaries are unchanged. The supplied template and the confirmed two-author details/declaration have been applied. The live journal Guide for Authors could not be retrieved (HTTP 403); check portal-specific requirements before submission.
