- Received-residual comparators use sensor/horizon scores when at least 50 exist and otherwise fall back to the same-dataset horizon pool. Rolling uses the higher empirical quantile; exponentially weighted scores decay by target time. These implementation choices must be locked on tuning data before paper evaluation.
- The ACI comparator follows the cited horizon-specific update, but uses one mean-miss update for each same-arrival spatial batch. It evaluates the originally issued interval and does not update before delayed feedback is released. This is an explicit project variant and does not inherit the source paper's finite-sample guarantee under delayed or missing outcomes.
- Full FAR-GW training uses both row-normalized supplied adjacency directions plus the learned adaptive support. Windows are constructed lazily; timestamp-derived time-of-day/day-of-week features and training augmentation are deterministic. Each epoch is resumable and its shuffle is derived from the model seed and epoch.
- A single CPU optimizer step took about 1.04 seconds on METR-LA and 1.88 seconds on PEMS-BAY at batch size 32. These are host-specific feasibility measurements, not model results. Full three-seed training is a multi-day CPU workload unless early stopping is rapid or CUDA PyTorch is configured.
- Prediction artifacts are streamed in 288-origin chunks and bind prepared data, checkpoint, and fault manifests by SHA-256. An independent C0 release-schedule replay reproduced all model quantiles and masks exactly. The first clean cache reconstructed truth through normalized float32 targets, causing at most 5.25e-6 mph round-trip difference; future caches retain source truth directly, and the legacy tolerance is explicit in the validation artifact.
- Online rolling and ACI comparisons retain only horizons 3/6/12, the registered reporting and primary-endpoint horizons. Exact per-node target-time windows use sorted stores; same-arrival ACI misses are averaged once per horizon/level. Paired real-data uncertainty resamples 24-hour time blocks and retains every valid sensor/horizon cell through block sums and counts.
